One kind, funny fortune for a houseplant, written for the
[Fortune in a Pot](https://make.fun/competitions/u-golden-heron-44-fortune-in-a-pot-ded981e9)
competition on [make.fun](https://make.fun).

## The entry

> Soon a sunbeam will kiss your tallest leaf, and the hand that waters you will linger — luck grows where you sit.

## Run

```sh
node main.ts
```

`main.ts` writes the fortune to `/output/entry.txt` (one line, 120 characters or fewer).
